I'm a freelance software engineer from Ecuador. I build **computer vision and edge AI** systems and the software
around them — web apps, distributed back-ends and business apps — with tests and CI from the first commit.

**Now**
- **Thesis:** MobileNetV3 INT8 recognizing AAC pictograms on an Arduino UNO Q — 92.5 % accuracy, 29.8 ms per image, no cloud.
- **Pliego:** an Overleaf-style collaborative LaTeX editor (Yjs, CodeMirror, live PDF), self-hosted on my Proxmox homelab.
- **Endify:** products like a CRM for clinics, a fitness app and a personal finance app (Angular, Next.js, Firebase).
